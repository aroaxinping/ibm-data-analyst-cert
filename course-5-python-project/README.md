# Course 5: Python Project for Data Science

**Duracion estimada:** 8 horas
**Modulos:** 1 (proyecto practico)

## Que cubre

Proyecto practico que aplica todo lo aprendido en el curso 4. Se trabaja con
datos financieros reales: historial de acciones y beneficios de empresas
(Tesla, GameStop). El objetivo es extraer datos, limpiarlos y crear un
dashboard de visualizacion basico.
