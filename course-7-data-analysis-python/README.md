# Course 7: Data Analysis with Python

**Duracion estimada:** 15 horas
**Modulos:** 6

## Que cubre

Analisis completo de datos con Python: importar datasets, EDA, limpieza
y wrangling con pandas, analisis descriptivo y correlaciones, y modelos
de regresion basicos para prediccion. El dataset principal es de precios
de automoviles.
