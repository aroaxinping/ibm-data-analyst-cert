# IBM Data Analyst Professional Certificate

Documentacion de notas, ejercicios practicos y capstone del IBM Data Analyst
Professional Certificate de Coursera (9 cursos).

---

## Sobre este repositorio

Recoge notas de aprendizaje, ejercicios practicos y el proyecto final (capstone)
de los 9 cursos del certificado. Pensado para poder rehacer cualquier ejercicio
desde cero y como referencia futura.

Para instrucciones de instalacion y como replicar cada entorno, ver [SETUP.md](./SETUP.md).

## El proceso de analisis

El certificado de IBM sigue un proceso similar al de Google pero con enfoque
mas tecnico desde el principio, incorporando Python y SQL desde el curso 4:

```
Recopilar -> Limpiar -> Analizar -> Visualizar -> Comunicar
```
