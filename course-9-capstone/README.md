# Course 9: IBM Data Analyst Capstone Project

**Duracion estimada:** 13 horas
**Modulos:** 6

## Que cubre

Proyecto final integrador. Se aplican todas las habilidades del certificado
en un caso real: recopilar datos de distintas fuentes (API, web scraping,
datasets), limpiarlos, analizarlos con SQL y Python, visualizarlos y
presentar los hallazgos.

**Tema:** Stack Overflow Developer Survey — tendencias en tecnologias,
lenguajes de programacion y herramientas mas demandadas en el mercado tech.

## Pregunta de negocio

¿Cuales son las tecnologias, lenguajes y bases de datos mas usadas actualmente
y cuales seran las mas deseadas por los desarrolladores en el futuro proximo?
