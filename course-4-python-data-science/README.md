# Course 4: Python for Data Science, AI & Development

**Duracion estimada:** 25 horas

## Que cubre

Python desde cero hasta un nivel funcional para data science. Tipos de datos,
estructuras, funciones, orientacion a objetos basica, pandas, NumPy y acceso
a APIs y web scraping.
