# Course 6: Databases and SQL for Data Science with Python

**Duracion estimada:** 20 horas
**Modulos:** 6

## Que cubre

SQL desde cero hasta consultas avanzadas: DDL, DML, funciones de agregacion,
JOINs, subqueries, vistas y procedimientos almacenados. Tambien cubre como
conectar Python a una base de datos SQL (IBM Db2) y ejecutar queries desde
un Jupyter Notebook.
