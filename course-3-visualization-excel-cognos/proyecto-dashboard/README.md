# Proyecto Final — Dashboard Automoviles

**Dataset:** datos de automoviles (fuel economy, fabricante, tipo de combustible)

## Dashboards creados

### Excel
- Grafico de barras: promedio de CO2 por fabricante (top 10)
- Grafico de lineas: evolucion del consumo (MPG) por año
- Tabla dinamica con slicer por tipo de combustible

### Cognos
- KPI: promedio MPG de la seleccion
- Scatter: potencia (HP) vs consumo (MPG)
- Filtros: año y fabricante
