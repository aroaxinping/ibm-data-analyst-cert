# Course 8: Data Visualization with Python

**Duracion estimada:** 20 horas
**Modulos:** 5

## Que cubre

Visualizacion de datos en Python con cuatro librerias: matplotlib (base),
seaborn (estadistica), Folium (mapas) y Plotly/Dash (interactivo y dashboards).
