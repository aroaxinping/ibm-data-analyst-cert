# Modulo 4: Pivot Tables

Semana 3 — Duracion estimada: 3 horas

## Que cubre

Creacion de tablas dinamicas, las cuatro zonas (Filas, Columnas, Valores,
Filtros), calculos disponibles y "mostrar valores como" (%, acumulado,
diferencia...), ordenar y filtrar dentro de la pivot, agrupacion de fechas
y numeros, jerarquias multicampo (drill-down), segmentaciones de datos
(slicers) y graficos dinamicos.

Incluye la configuracion exacta de las tres pivot tables del final assignment
(Montgomery Fleet) y el analisis de los resultados.
