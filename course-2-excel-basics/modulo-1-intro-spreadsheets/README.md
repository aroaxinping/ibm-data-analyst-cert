# Modulo 1: Introduction to Spreadsheets

Semana 1 — Duracion estimada: 2.5 horas

## Que cubre

Estructura de una hoja de calculo (celda, rango, hoja, libro), tipos de datos
por celda, tabla de errores comunes (#REF!, #N/A, #DIV/0!...), referencias
relativas, absolutas y mixtas con la logica del $, formulas de agregacion
basicas (SUMA, PROMEDIO, MAX, MIN, CONTAR, CONTARA, CONTAR.SI) y atajos
de teclado esenciales.
