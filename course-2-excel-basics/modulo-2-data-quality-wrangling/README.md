# Modulo 2: Data Quality and Data Wrangling in Spreadsheets

Semana 1-2 — Duracion estimada: 3 horas

## Que cubre

Deteccion y eliminacion de duplicados, tratamiento de valores vacios,
conversion de tipos de datos incorrectos (texto a numero, fechas como texto),
funciones de limpieza de texto (ESPACIOS, SUSTITUIR, MAYUSC, NOMPROPIO,
IZQUIERDA, EXTRAE), buscar y reemplazar masivo, Flash Fill y formato
condicional para deteccion visual de problemas.

Incluye documentacion del proceso real aplicado al dataset de Montgomery Fleet
Equipment Inventory (final assignment del curso).
