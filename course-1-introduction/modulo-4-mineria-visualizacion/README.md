# Modulo 4: Mining & Visualizing Data and Communicating Results

Semana 3 — Duracion estimada: 2.5 horas

## Que cubre

Analisis exploratorio de datos (EDA), estadisticas descriptivas, correlacion
vs causalidad, tecnicas de mineria de datos (clasificacion, regresion,
clustering, asociacion, deteccion de anomalias), principios de visualizacion,
tipos de grafico segun el proposito, y como adaptar la comunicacion de
resultados segun el publico.
