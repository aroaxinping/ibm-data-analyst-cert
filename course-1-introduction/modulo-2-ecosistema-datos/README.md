# Modulo 2: The Data Analyst Ecosystem

Semana 1-2 — Duracion estimada: 3 horas

## Que cubre

Tipos de datos (estructurado, semi-estructurado, no estructurado), fuentes
de datos internas y externas, el ecosistema de herramientas por etapa,
repositorios de datos (RDBMS, Data Warehouse, Data Lake, Data Mart),
OLTP vs OLAP, y el flujo completo desde la fuente hasta el analisis.
