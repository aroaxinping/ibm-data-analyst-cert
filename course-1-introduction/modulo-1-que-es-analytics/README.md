# Modulo 1: What is Data Analytics?

Semana 1 — Duracion estimada: 3 horas

## Que cubre

Los cuatro tipos de analisis (descriptivo, diagnostico, predictivo, prescriptivo),
el rol del analista de datos frente a otros roles del ecosistema, y el proceso
de analisis de principio a fin. Modulo conceptual, sin herramientas ni codigo.
