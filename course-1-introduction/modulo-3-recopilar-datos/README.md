# Modulo 3: Gathering and Wrangling Data

Semana 2 — Duracion estimada: 2.5 horas

## Que cubre

El proceso de recopilacion de datos, las seis dimensiones de calidad de IBM
(exactitud, completitud, consistencia, oportunidad, credibilidad, relevancia),
estrategias para tratar nulos, duplicados, outliers y formatos inconsistentes,
y las herramientas de wrangling (Excel Power Query, pandas, SQL, OpenRefine).
